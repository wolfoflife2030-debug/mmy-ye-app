# MMY.YE — نسخة ويندوز وأندرويد

مشروع واحد ينتج **برنامج ويندوز (.exe)** و**تطبيق أندرويد (.apk)** من ملف النظام `src/index.html`.
ملف النظام لا يُعدَّل أثناء البناء؛ كل ما يخص التطبيقات الأصلية في `src/native-bridge.js` ومجلدي `electron/` و`native/`.

## البناء التلقائي على GitHub (الأسهل — بدون تثبيت شيء)
1. ارفع محتوى هذا المجلد إلى مستودع GitHub خاص.
2. Actions ← **Build Windows & Android** ← Run workflow.
3. نزّل `windows-installer` و`android-apk` من Artifacts.

## البناء على جهازك
المتطلبات: Node.js 20+ ، ولأندرويد أيضاً Android Studio (JDK + SDK).
```
npm install
npm run dev              # تجربة نسخة ويندوز مباشرة
npm run win              # ينتج dist/*.exe (مثبّت + نسخة محمولة)

npm run android:add      # مرة واحدة
npm run android:setup    # يضيف دعم البصمة لمشروع أندرويد المولَّد
npm run icons            # أيقونات أندرويد من مجلد assets
npm run android:open     # يفتح Android Studio ← Build > Build APK(s)
```

## البصمة
- **أندرويد:** نافذة البصمة الرسمية (BiometricPrompt). تتطلب بصمة مسجّلة في إعدادات الجهاز.
- **ويندوز:** Windows Hello (بصمة الإصبع أو الوجه أو PIN حسب ما فعّله المستخدم في ويندوز).
- **التفعيل:** ادخل بكلمة المرور ← إعدادات البرنامج ← «تسجيل الدخول بالبصمة» ← «تسجيل هذا الجهاز». بعدها يطلب البرنامج البصمة تلقائياً عند فتح شاشة الدخول، وكلمة المرور تبقى متاحة دائماً.
- البصمة هنا **قفل دخول محلي** كبقية النظام: لا تُنقل بين الأجهزة ولا تُخزَّن صورتها. تُسجَّل لكل جهاز على حدة.
- في المتصفح العادي يبقى سلوك النظام الأصلي (WebAuthn) كما هو.

## لتحديث النظام لاحقاً
استبدل `src/index.html` (وأبقِ `src/logo.webp` بجانبه) ثم أعد البناء. البيانات على الجهاز لا تُمسّ.

## ملاحظات
- **البيانات** محلية على كل جهاز (localStorage + IndexedDB) دون مزامنة. استخدموا «تصدير نسخة احتياطية» دورياً؛ على أندرويد يفتح التصدير قائمة المشاركة/الحفظ.
- **توقيع APK:** الناتج `debug` للتجربة والتوزيع الداخلي. النشر في Google Play يحتاج مفتاح توقيع و`bundleRelease`.
- **ويندوز SmartScreen** قد يحذّر من ملف غير موقَّع إلى أن تُضاف شهادة توقيع.
- الشعار: `src/logo.webp` (يُستخدم في الواجهة)، وأيقونات التطبيق في `assets/` و`build/icon.png`.
